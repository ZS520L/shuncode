# ShunCode

> 让网页版 ChatGPT 直接写你的代码

ShunCode 是一款**一次买断、本地运行的 AI 代码编辑器**，基于 VS Code 深度定制。

利用网页版 ChatGPT / Claude / Grok 支持自定义 MCP 连接器这一官方特性，把你已有的订阅变成编程 Agent —— 无需另买 API，大幅节省成本。同时内置完整本地 AI Agent，兼容全部 VS Code 插件生态。

## 旗舰功能：网页版 ChatGPT / Claude / Grok 接入

ChatGPT、Claude、Grok 的网页版均官方支持添加自定义 MCP 连接器。ShunCode 内置 Bridge 服务，把你的本地项目安全地暴露给网页版 AI —— 你在网页里聊天，AI 在你的编辑器里干活。

- **大幅节省成本**：无需按 token 计费的 API。用你已有的 ChatGPT Plus / Claude Pro / Grok 订阅，固定月费就能获得完整的编程 Agent 体验。
- **完整工具链**：网页版 AI 可直接读写文件、搜索代码、执行命令、汇报进度；改动以行内 Diff 呈现，审阅回滚都在你掌控中。token 路径保护，安全可控。
- **MCP Hub**：同时支持连接外部 MCP Server，工具、资源、文档自动注入 Agent 工具系统。

> **诚实声明**：本产品仅是一款本地编辑器工具。我们不出售任何 AI 账号、不提供代付代充、不提供任何 API 中转或代理服务。接入能力基于 ChatGPT / Claude / Grok 网页版公开提供的自定义 MCP 连接器特性，你需自行拥有并遵守对应平台的账号与服务条款。

ShunCode 不是账号店、不是 API 中转站、不是订阅制 SaaS。你买的是一把"钥匙"：把你自己已经在付费的 AI 订阅和 API，变成一个真正能干活的编程 Agent。代码不离开你的电脑，钱不经过我们的手。

## Agent 核心能力

- **智能文件操作**：读取 / 批量读取、新建、替换、补丁、Hashline 精准编辑、Notebook 编辑，改动以行内待处理 Diff 呈现，随时审阅回滚。
- **深度代码理解**：语义检索、并行搜索子代理、正则 / glob 搜索、定义跳转、引用查找、hover 与诊断读取，让 AI 真正看懂你的项目。
- **执行与验证**：终端命令执行与后台输出追踪、浏览器自动化操作、网页搜索与抓取，写完代码自己跑、自己验。
- **高自由度定制**：系统提示词、工具集均由你自己掌握和定制。Agent 的能力上限握在你自己手中，而不是被厂商预设锁死。
- **扩展与记忆**：MCP 工具 / 资源接入、技能（Skills）加载、持久记忆、任务拆分、图片生成、任务评估，能力可持续生长。
- **流程控制**：追问澄清、完成回复、Plan / Act 一键切换、任务进度链路可视化，人机协作节奏由你掌控。
